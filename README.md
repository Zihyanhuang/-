# 🤖 日照中心 凱比機器人長者認知分數數位化系統

> 本專案為長照 2.0 **日間照顧中心** 量身打造，結合 **女媧創造凱比機器人 (Kebbi Air)** 的高親和力互動優勢，將長者例行認知評估（如 SPMSQ）與日常五感動腦訓練全面數位化，省去照服員紙本謄寫時間，並自動產出五向能力雷達圖與衰退預警。

---

## 🌟 系統亮點與功能特色

1. **長者友善去挫折互動設計 (`kebbi_app`)**：
   - **超大觸控按鈕與高對比視覺**：針對長輩視力退化與關節僵硬設計，單鍵高達 90px。
   - **凱比擬真語音朗讀 (TTS)**：語速自動放慢至 0.85x，語調溫和，支援「🔊 凱比再唸一次」。
   - **正向回饋激勵**：答對播放和弦音，即使答錯也以「動動腦就很棒」溫柔鼓勵，保護長者自尊心。
2. **雙評估模式**：
   - **📋 SPMSQ 簡短智能評估量表**：臨床標準 10 題（年齡、日期、日照地點、總統姓名、日常倒減算數），自動計算錯題數與心智等級。
   - **🎮 五感動腦趣味挑戰**：結合日常生活記憶（三件寶物短期與延遲記憶）、買菜找零計算、影子輪廓辨識、生活常識邏輯。
3. **照護管理儀表板 (`dashboard`)**：
   - **🎯 五向能力雷達圖**：分析定向感、記憶力、計算力、知覺、語言五大維度（純原生 SVG 渲染，免網路外掛）。
   - **📈 歷史趨勢折線圖**：歷次測驗分數走勢，自動標記 60 分警戒線與 80 分優良線。
   - **🚨 認知衰退自動預警**：若長者分數較前期下滑 ≥ 15 分或 SPMSQ 錯題數增加，自動亮紅燈提示轉介複評。
   - **🖨️ 評鑑報告列印與 CSV 匯出**：一鍵產生 A4 評鑑專用表單與 Excel 報表。
4. **極高環境相容性 (雙模支援)**：
   - **離線模式**：直接點擊 HTML 即可在任何瀏覽器、平板或凱比螢幕運作（自動以 LocalStorage 存檔）。
   - **伺服器模式**：內建免安裝 Python 本地服務與 SQLite 資料庫，日照中心區網內多台設備可同時連線同步。

5. **日照實習時序跑關與智能鬧鐘 (`daycare_flow`)**：
   - **📅 一週五天行事曆排程**：週一至週五特色主題（延緩失能肌力、凱比動腦、園藝綠活、益智桌遊、慶生同樂會）。
   - **⏰ 照服員智能鬧鐘提醒**：原生 Web Audio 清脆和弦鈴聲 ＋ Web Speech API 擬真語音各時段貼心廣播。
   - **🍂 台灣 24 節氣與國定假日感應**：霜降、冬至、大暑等時令節氣自動對照，晨間問候連動長者健康照護小叮嚀。
   - **🏃‍♂️ 六大實習時段跑關**：09:30 現實導向與生徵警戒 ➔ 10:00 主活動1與凱比 ➔ 11:40 午餐口腔用藥 ➔ 13:00 主活動2 ➔ 15:30 點心接送 ➔ 16:30 末班車與全所安全零滯留結案。
   - **📋 實習總結日報列印與匯出**：一鍵產生 A4 日誌，支援示範數據模擬快填。

## 🚀 快速啟動與操作步驟

### 方式一：Windows 一鍵啟動（最推薦）
直接滑鼠雙擊專案目錄下的 **`啟動日照認知系統.bat`**：
- 系統將自動偵測環境，啟動後端資料庫並在瀏覽器同時開啟：
  1. 🤖 凱比互動端 (`http://localhost:8000/kebbi_app/index.html`)
  2. 📊 照護管理後台 (`http://localhost:8000/dashboard/index.html`)

### 方式二：手動執行 Python 本地伺服器
在命令提示字元 (CMD / PowerShell) 執行：
```bash
python backend/server.py
```
隨後以瀏覽器開啟 `http://localhost:8000/dashboard/index.html`。

### 方式三：完全免伺服器直接開啟（最輕量）
直接雙擊開啟 `daycare_flow/index.html`、`kebbi_app/index.html` 或 `dashboard/index.html` 即可完整使用所有功能，數據安全保存在瀏覽器本機內！

## 🤖 凱比機器人實機載入方式

若要在凱比機器人 (Kebbi Air) 上執行：
1. **內建瀏覽器 / Kiosk 模式**：
   - 將凱比連線至日照中心的 Wi-Fi。
   - 在凱比螢幕上打開瀏覽器，輸入本地伺服器 IP（如 `http://192.168.1.100:8000/kebbi_app/index.html`）或直接載入本網頁。
   - 點擊全螢幕即可作為長者每日動腦互動站。
2. **語音發音相容性**：
   - 程式採用 Web Speech API 與 Web Audio API，相容於 Android WebView、Chrome、Edge 與 Safari。
